  input lag น้อย   (เป็นการปรับ Windows ของตัวเอง ไม่ใช่โปรแกรมโกง)

 มีอะไรใหม่ใน v5.0
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  • Dashboard + เกจ "Tuned %"  ที่ไต่ขึ้นเมื่อ apply tweak
  • ปุ่ม Optimize all  คลิกเดียวปรับทุกอย่าง
  • Profiles สำเร็จรูป: Competitive / Balanced / Streaming / Max
  • ค้นหา tweak ได้ + จำสถานะที่ apply ไว้ (แม้ปิดแอพ)
  • Restore: สร้างจุดกู้คืน Windows / ย้อนค่าที่ปรับ / รีเซ็ต power plan
  • รันคำสั่งจริงในตัวแอพ (ไม่ต้องโหลด .ps1 แยกแล้ว)
  • อ่าน spec เครื่อง (CPU / GPU / RAM) มาแสดงอัตโนมัติ
  • Activity log + export, Toast แจ้งเตือน, ดีไซน์ใหม่ทั้งหมด


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 อัปเดตเพิ่มเติม (หมวดใหม่)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  🎮 FiveM       - ตั้ง priority สูงให้ FiveM (ถาวร), ล้าง
                   server-cache / browser-cache / logs
                   (เขียนเพื่อ FiveM เป็นหลัก + ได้ผลเกมอื่น)

  📡 Auto Ping   - วัด ping จริงหลาย DNS (Cloudflare/Google/
                   Quad9/OpenDNS) แล้วเลือก+ตั้งตัวเร็วสุดให้
                   อัตโนมัติ ตรวจอะแดปเตอร์ด้วย index รองรับ
                   LAN/WiFi และ Windows ทุกภาษา

  🛡️ Policy      - ปรับ Group Policy ผ่าน registry (ไม่ต้องมี
                   gpedit.msc): กัน Windows Update รีบูตตอนเล่น,
                   ปิด Delivery Optimization / Background Apps /
                   Telemetry / Game DVR / Network Throttling

  ⏹️ Services    - หยุด service ที่ไม่จำเป็น (Manual = คืนค่าได้)
  ⛔ Services    - ปิด service ถาวร (Disabled) แบบมี guard
     (ปิดถาวร)     ใช้ได้ทุก build ตัวไหนไม่มีจะข้ามให้อัตโนมัติ

  * ทุกหมวดมีปุ่มคืนค่า และปุ่ม Revert everything หน้า Restore
    ครอบให้ทั้งหมด  ·  รวม 45 tweaks

 สิ่งที่ต้องมีก่อน (ทำครั้งเดียว)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  ติดตั้ง Node.js (LTS) จาก  https://nodejs.org
   - ติดตั้งแบบปกติ (ติ๊ก "Add to PATH")
   - หลังติดตั้งเสร็จ RESTART เครื่อง 1 ครั้ง


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 วิธีสร้างแอพ (.exe)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  1. Copy โฟลเดอร์นี้ไปไว้ที่  C:\GameBoost
     ** สำคัญ: path ต้องไม่มีภาษาไทย **

  2. ดับเบิ้ลคลิก  BUILD.bat   แล้วรอ 3-5 นาที
     จนขึ้น  BUILD SUCCESS!

  3. โฟลเดอร์ win-unpacked จะเปิดขึ้นมาเอง
     ในนั้นมีไฟล์  GameBoostFPS.exe

  4. คลิกขวา GameBoostFPS.exe -> Send to -> Desktop (create shortcut)

  5. ดับเบิ้ลคลิก shortcut บน Desktop เปิดแอพได้เลย!
     (แอพจะขอสิทธิ์ Administrator เองอัตโนมัติ)

 วิธีใช้แอพ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  - Dashboard: กด "Optimize all" ปรับทุกอย่างในคลิกเดียว
  - Profiles:  เลือกชุดที่เหมาะกับสไตล์ แล้วกด Apply profile
  - แต่ละหมวด: กด Apply ทีละอัน หรือ Apply all ทั้งหมวด
  - Restore:   สร้าง restore point ก่อนปรับ / ย้อนค่าได้ทุกเมื่อ
  - Restart เครื่องหลังปรับเสร็จ เพื่อให้ทุกค่ามีผลเต็มที่

  ครั้งต่อไปเปิดจาก shortcut ได้เลย ไม่ต้อง BUILD ซ้ำ
