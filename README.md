# Game Boost FPS — blocklist

This repository only hosts `blocklist.json`, the signed list Game Boost FPS
reads at startup to switch off a tweak that misbehaves on some Windows builds.

- The file is signed (Ed25519). The app ignores anything not signed by the developer.
- The program itself is not distributed here.
